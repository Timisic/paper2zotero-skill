# 安装与使用帮助

第一次配置只有四步：准备工具 → 连接 Zotero → 启用全文阅读 → 检查结果。

Zotero 保存你的论文和笔记；全文阅读使用 MinerU，将 PDF 转成便于阅读和总结的文字。两个服务各有自己的账号。向导会打开对应网页并逐步说明如何取得授权码，不需要学习编程。

## Windows

- 使用普通 PowerShell 或双击下载目录中的 `install/setup.cmd`，无需安装 WSL，也不需要手动改系统路径。
- 安装过程中可能出现系统的安装许可窗口。完成后会打开标题含 **Windows 图形向导 v2** 的普通窗口。
- 在输入框按 **Ctrl+V**，或点击旁边的 **粘贴** 按钮。输入以圆点遮蔽，并显示“已收到输入”。点击 **验证并保存**，连接成功后才保存；失败会留在当前页供你修改、重试。
- 个人文库 ID 自动识别，不需要填写。网络或授权失败会在窗口内说明原因。“暂时跳过”保留原有配置。
- 点击“打开授权页面”会调用 Windows 默认浏览器；若没有打开，旁边的网址可以选中复制。
- 如果你看到旧的 `Stage 2/4` 终端界面，说明仍在运行旧下载或备用入口。请重新运行首页的在线安装命令获取新版，或让助手更新实际安装副本。普通 `setup.cmd` 只运行当前下载的版本，不会自动更新仓库。
- 完成页点击 **更多设置（可选）** 可继续配置浏览器全文和检索来源；也可双击 `setup-more.cmd` 直接打开同一个图形设置页。需要备用终端时用 `setup.ps1 -Terminal`；终端进阶流程加 `-Advanced`。
- 如果系统提示缺少“应用安装程序”，按打开的 Microsoft Store 页面安装或更新，然后重跑原入口。
- 若网络下载失败，网络恢复后重跑；已经填写的账号配置会保留。
- 通过在线命令安装后，可按 Win+R，输入 `%LOCALAPPDATA%\paper2zotero-source\install\setup.cmd`，继续配置。
- 安装路径可以包含中文和空格。软件安装完成后仍提示找不到工具时，关闭旧窗口，再运行安装入口。

## 更多设置

默认配置完成后，即可开始使用。额外文献来源、电脑上的 Zotero 附件下载，以及通过学校或机构浏览器访问全文，可以等需要时再设置。

Windows 基础配置的完成页会提供 **更多设置（可选）** 按钮，不用重新填写基础账号。每项先说明用途，再提供官网、输入框或连接检查。也可以请 AI 助手“打开文献工具的更多设置”，或自己运行：

- Windows：双击 `install/setup-more.cmd`。
- macOS/Linux：`bash install/setup.sh --advanced`。

更多设置里的每项都可跳过。跳过会保留之前的配置；之前已经启用的功能仍会在最后检查。

- **Kimi WebBridge**：从学校或机构的已登录浏览器获取全文。按官网“搭配本地 Agent”安装连接服务和扩展，然后点击“启动并检查”；扩展连接通过后才启用。
- **Semantic Scholar / OpenAlex**：补充学术检索的账号授权。向导提供申请页面；申请尚未完成可以以后再来。原生设置页保存授权码，但不把“已保存”视为“已验证”，来源可用性会在实际检索时报告。
- **Crossref / Unpaywall**：分别用于题录查询和开放全文定位，只需联系邮箱。邮箱会随请求发送给对应服务，不需要邮箱密码。
- **Zotero Desktop**：引导启用本地 API 和附件同步，并检查本机状态。

图形界面仅由 Windows 入口加载。macOS/Linux 仍使用 Bash 向导，无需 Tk 或 PowerShell；基础四步和 `--advanced` 入口保留。

## 没有账号或授权码

直接回车暂时跳过。向导会说明哪些功能还不能使用，可以先尝试找论文；服务是否可用还取决于网络和对应服务的访问额度。需要保存到 Zotero 或生成全文阅读材料时，再补齐对应账号。

## 更换总结提示词

可以保留默认分析方式，也可以换成自己熟悉的提示词。setup 最后会询问是否查看修改位置；这一步只显示说明，不编辑文件。

修改**当前助手实际加载的 skill** 中的 `references/paper-summary.md`。官方安装器的默认位置如下，自定义安装目录以 setup 显示的绝对路径为准：

| 安装方式 | 要修改的文件 |
| --- | --- |
| macOS / Linux | `~/.local/share/literature-to-zotero/skill/references/paper-summary.md` |
| Windows · Codex | `%USERPROFILE%\.codex\skills\literature-to-zotero\references\paper-summary.md` |
| Windows · Claude Code | `%USERPROFILE%\.claude\skills\literature-to-zotero\references\paper-summary.md` |
| Windows · Pi | `%USERPROFILE%\.pi\agent\skills\literature-to-zotero\references\paper-summary.md` |

用文本编辑器打开它，把前半部分的阅读分析要求替换为自己的提示词，保留 **`## Save and continue` 及之后**的保存／续跑说明。无需修改密钥或其他账号配置。保存后在新文献任务中使用；已经生成的笔记不会自动重写。更新或重装可能覆盖这个文件，请自行保留自定义提示词副本。

## 预览界面

Windows 双击 `install/setup-demo.cmd`，macOS/Linux 运行 `bash install/setup.sh --demo`。这只是演示，不安装软件、不连接账号、不上传论文，也不会改变真实配置。Windows 预览需要已有 Python（含 Tk）和 Git Bash，可用“复制示例授权码”测试粘贴；请勿输入真实授权码。

## 助手里找不到技能

新开一个助手会话再试。仍找不到时，让助手“检查 literature-to-zotero 是否安装到了当前助手”。同一份技能支持 Claude Code、Codex 和 Pi；安装到一个助手不会自动使所有助手都能使用。

## 论文和数据会发送到哪里

- 找论文时，会把检索词、题名或论文编号发送给学术搜索服务。
- 你确认保存后，论文和阅读笔记会写入你的 Zotero 账号；已有条目会先按论文身份检查是否可复用。
- 生成格式化阅读材料时，需要将整篇 PDF 上传到 MinerU。助手会取得覆盖这些论文的许可；不允许上传时，会保留已取得的 PDF，并说明缺少哪些材料。
- 使用机构访问时，浏览器会访问相应出版社或数据库，并使用已有登录状态。交给 AI 阅读的论文文本也会进入当前助手的处理流程；具体数据处理方式取决于你使用的助手和服务。

账号授权码保存在本机配置中。任务目录会保留 PDF、阅读材料和处理进度，方便继续；不要把含授权码的配置或不希望公开的任务资料提交到公开仓库。

## 使用中的常见问题

| 遇到什么 | 怎么继续 |
| --- | --- |
| Zotero 有条目，但电脑上打不开附件 | 打开 Zotero 的同步设置，确认附件同步和自动下载已开启，再点同步。仍打不开时让助手检查该附件的下载状态，先不要重复导入。 |
| 某篇论文获取失败或要求登录 | 按实际打开的网页完成学校、机构或出版社登录；让助手继续原任务。多篇失败不一定是同一种原因。 |
| 全文阅读授权失效，或解析一直失败 | 重跑向导检查全文阅读账号；确实失效时再更新授权码。已下载的 PDF 会保留。 |
| 阅读材料中的表格或文字不对 | 以原始 PDF 为准，让助手核对具体页面。转换和总结都可能出错。 |
| 任务中断，只处理了一部分 | 说“继续上次的任务”；保留原任务目录，助手会读取已完成的步骤。 |
