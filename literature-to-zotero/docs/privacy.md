# 隐私与数据边界

本 skill 会与若干外部服务交互。原则：**每次把内容发给第三方前需要你的同意；能本地/只读就不外发；凭据永不进入聊天、日志或运行包。**

## 数据流向

| 服务 | 发送什么 | 何时发生 | 默认 |
|---|---|---|---|
| OpenAlex | 检索词（研究意图的关键词/布尔式），**不含附件原文** | 候选发现 | 自动 |
| Crossref / OpenCitations / Semantic Scholar | 检索词、DOI、题录查询 | 元数据校正/补源 | 自动/按需 |
| Zotero Web API + zotero.org | 条目元数据、PDF 附件、Markdown 附件、note | 入库 | 需你已确认候选后 |
| **MinerU** | **整篇 PDF 内容**（用于解析成 Markdown） | 每篇文献解析 | **需要明确同意 + 已配 token**；解析结果在你自己的账号下生成 |
| Kimi 浏览器扩展 | 无内容外发；它在**你的浏览器**里用你的登录态操作页面 | 获取原文 PDF | 需扩展已连接 |
| 远端下载（官方 OA、出版社页） | 请求 URL；可能携带你的会话（MyLOFT 等） | 获取原文 | 使用你浏览器的既有登录态 |

## 你的责任与提醒

- **MinerU 云解析**会把论文全文上传到第三方云端（mineru.net）。对受订阅保护、未公开发布或保密材料，请在开启前确认合规。
- **Kimi** 会以你的真实账号身份访问出版社/数据库；请只用于你本人有合法访问权的全文。
- API key/token（Zotero、MinerU）创建后若曾出现在聊天里，请立即撤销重建。
- 本地 run package（`literature-runs/…`）会保存你下载的 PDF 与解析 Markdown——这是你自己的机器，注意备份与清理策略。

## 记录

`preflight`/`setup doctor` 与各脚本只在本地报告“是否已配置”，绝不回显凭据。实际向哪些外部服务发送了什么，记录在 run package 的 manifest（审计事件）里。
